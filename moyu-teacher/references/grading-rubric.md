## 1. 好标准的五条要求

1. **基于可观察行为**：给分点描述学生"写出/做出/说出"了什么，不描述"态度认真""有想法"这类无法观察的印象。
2. **相互独立、穷尽合理答案**：各采分点不重复计分；多解题列出全部等价解法与可接受表述。
3. **分值闭合**：各题满分之和 = 卷面满分；一道题内各采分点分值之和 = 该题满分；量表各维度加权之和 = 100%。
4. **边界清晰**：相邻档位/给分点之间有可区分的描述词，避免"较好""一般"单独出现——要写出"较好"具体好在哪。
5. **先于评分确定、留痕可溯**：标准在正式评分前写定；试评后修订要记录修订原因，并对已评份数回溯适用。

选择评分方法：

| 题型/任务 | 推荐方法 |
|---|---|
| 选择、判断、匹配 | 标准答案（对/错） |
| 填空 | 标准答案 + 可接受答案清单 |
| 计算、证明、解方程 | 采分点法（步骤分） |
| 简答、名词解释、材料分析 | 采分点法（要点分），辅以质量档位 |
| 论述、案例分析 | 分项量表或整体分级量表 |
| 作文、开放写作 | 分项量表 |
| 编程、实操 | 采分点法（用例 + 技术点 + 质量） |
| 设计、作品、口语展示 | 分项量表 |

## 2. 采分点法（分步/要点给分）

把一道题的满分拆成若干**采分点**（得分点），每个采分点对应明确的作答表现和固定分值；
同时列出典型错误的扣分位置。

编制步骤：

1. 自己先完整做一遍题（或核对参考答案），记录自然的解题步骤链/答题要点；
2. 每个关键步骤/要点分配分值，步骤越关键、越能体现考查目标，分值越高；
3. 标注哪些是**核心采分点**（整题意图所在，缺失即大扣分），哪些是次要分（单位、书写）；
4. 为每个采分点写 1 句"出现什么表述/结果即给分"；
5. 列出 2~4 个常见错误及对应扣哪个采分点；
6. 校验采分点分值之和 = 题目满分。

示例（计算题，满分 10 分）：

> 题目：用求根公式解 2x² − 5x − 3 = 0。

| 采分点 | 给分表现 | 分值 |
|---|---|---|
| P1 | 正确写出 a=2, b=−5, c=−3 | 1 |
| P2 | 正确写出求根公式 | 2 |
| P3 | 正确算出判别式 Δ=49 | 2 |
| P4 | 代入并求出 x = 3 | 2.5 |
| P5 | 求出 x = −1/2 | 2 |
| P6 | 结论完整（两个解、书写规范） | 0.5 |

常见错误扣法：Δ 算错但代入流程正确 → 扣 P3，P4/P5 按其 Δ 值正确代入的给分（错误不传导）；
只写结果无过程 → 只给 P4+P5 共 4.5 分。

## 3. 分级量表法（整体评分）

适用于整体性强、不易拆点的任务（小论述、短简答、口头表达）。
把分数区间划成若干档，**每档写出可观察的达成描述**，评分时先定档再在档内微调。

示例（论述题，满分 10 分）：

| 档位 | 分数 | 达成描述（满足该档全部特征） |
|---|---|---|
| 优秀 | 9~10 | 论点明确；覆盖全部 3 个核心要点且展开论证；至少 1 个恰当例证/材料支撑；逻辑连贯，无事实错误 |
| 良好 | 7~8 | 论点明确；覆盖 2~3 个核心要点；有论证但展开不充分；逻辑基本连贯，无硬伤 |
| 合格 | 5~6 | 有论点；覆盖 1~2 个要点；以罗列为主、论证薄弱；存在不影响主旨的小瑕疵 |
| 不合格 | 0~4 | 无明确论点或严重偏题；核心要点缺失；存在明显事实错误或逻辑断裂；字数严重不足 |

定档纪律：**先套描述定档，再在档内按好坏给分**；介于两档之间时，逐条比对描述，
不得因为字迹、好感等量表外因素跨档。

## 4. 分项量表法（多维度评分）

适用于作文、作品、案例分析等需要分别评价多个维度的任务。
每个维度单独设档位描述与权重，维度分合计为总分。

示例（作文，满分 40 分）：

| 维度（权重） | 优秀（满档） | 合格（中档） | 不合格（低档） |
|---|---|---|---|
| 立意审题（10） | 切题且立意深刻、有见解（8~10） | 符合题意、立意明确（5~7） | 偏题或立意不清（0~4） |
| 内容材料（10） | 内容充实、材料贴切新颖（8~10） | 内容完整、材料恰当（5~7） | 空洞或材料失当（0~4） |
| 结构条理（8） | 结构严谨、衔接自然（7~8） | 结构完整、条理清楚（4~6） | 结构残缺、条理混乱（0~3） |
| 语言表达（8） | 准确流畅、有文采（7~8） | 通顺、语病少（4~6） | 不通顺、语病多（0~3） |
| 书写规范（4） | 卷面整洁、无错别字（4） | 较整洁、少量错别字（2~3） | 潦草、错别字多（0~1） |

另列**硬性规则**（不属量表、单独执行）：少于规定字数每少 100 字扣 1 分；
未完成按评分说明降档；抄袭/套作按校规处理（评分官只标记不裁决）。

## 5. 常见题型给分模板

- **选择题/判断题（每题 n 分）**：答案唯一，答对 n 分、答错/不答 0；若题面规定少选得分、错选不得分，照题面写。
- **填空题（每空 n 分）**：标准答案 + 可接受答案（同义词、单位、大小写规则）；关键术语错别字扣该空，笔误按第 6 节。
- **计算题**：公式/列式分 + 过程代入分 + 结果分 + 结论规范分（参考第 2 节六采分点结构，按题裁剪）。
- **证明题**：已知转化分 + 关键定理/依据引用分 + 推导链完整分 + 结论分；逻辑跳跃按缺失环节扣。
- **简答题**：每个要点固定分值（要点分合计占 70%~80%）+ 表达条理分（20%~30%）。
- **编程题**：编译/运行通过（或静态可读）占比明确；每个测试用例/功能点固定分值；关键算法点分；代码规范分（建议 ≤10%）。
- **翻译/外文题**：关键信息点准确分 + 语句通顺分 + 术语规范分。
- **作图/表格**：要素完整性（标题、坐标、图例、单位）+ 正确性 + 规范分。

## 6. 常见扣分规则库

> 以下规则**只有在老师的评分标准未规定、且向老师说明后才统一适用**；老师另有规定从其规定。

- **笔误与结果分**：方法与过程正确、仅最后誊写/算术笔误，只扣结果分（通常 0.5~1 分或该题结果分），不重复扣过程分。
- **单位与有效数字**：缺单位、单位错误按处扣并设总上限（如全卷最多扣 2 分）；有效数字按题目要求。
- **错别字**：非关键术语的错别字累计到阈值再扣（如每 3 个扣 1 分，上限 2~3 分）；改变术语含义的按内容错处理。
- **卷面与格式**：未按要求写姓名/步骤/文件命名等，按老师事先公布的规则扣；没有规则不临时创设。
- **错误不传导**：前步错误导致后步结果错，但后步方法与运算正确，后步不扣分。
- **多答与选答**：选答题答多了，按得分最高的规定数量计；错误并列答案按标准处理（常见规则：有错则该点不给分）。
- **迟交/补交**：必须有老师明示的规则才扣，通过 grades.json 的 adjustment 字段记录原因。
- **奖励分**：除非老师事先规定，不设"写得多安慰分""辛苦分"；创见加分同样要事先有规则。

## 7. 等级与合格线划定

- 老师有规定（分数段、等第、合格线）：原样写入 grades.json 的 `pass_score` 与 `grade_boundaries`。
- 没有规定时，可向老师建议常见百分制方案，确认后使用：

| 等级 | 分数区间 |
|---|---|
| 优秀（A） | 90~100 |
| 良好（B） | 80~89 |
| 合格（C） | 60~79 |
| 不合格（D） | 0~59 |

- 合格线通常 60 分；考查类/通过性作业可按"核心采分点全部命中即合格"描述，而非只看总分。
- 等级边界要与采分点/档位协调：贴线卷（±2 分）在 B5 阶段一律人工复核。

## 8. 定标检查清单与文档模板

**定标完成检查清单**

- [ ] 每道题都有：题型、满分、参考答案/可接受答案、采分点或量表档位
- [ ] 各采分点/维度权重分值之和 = 该题满分；各题满分之和 = 卷面满分
- [ ] 多解题列出了等价解法；开放题写明了"评论证质量不评立场"
- [ ] 常见错误有明确扣法；错误不传导、笔误等规则口径统一
- [ ] 合格线、等级划分、迟交规则已与老师确认（或明确标注"待确认"）
